Copilot Glossary

Terms used across every lesson. Every lesson sticks to these meanings. Verified against Microsoft's pages on 2026-10-08 to 2026-10-10.

TermMeaningYou already know it as
Microsoft 365 PremiumThe home subscription (1 to 6 people, personal Microsoft account). Copilot in the Office apps, the Copilot app, Researcher, higher usage limits, Cowork in preview. AI features are for the account owner only.Your personal Claude or ChatGPT plan.
Microsoft 365 Copilot (work)The work product. Three licence levels: Copilot Chat (Basic), Microsoft 365 Copilot (Basic), Microsoft 365 Copilot (Premium). Only the top one reads your work data automatically.The company Claude for Work or Team plan.
Copilot ChatThe chat surface. At work it opens at copilot.cloud.microsoft, in the Copilot app, in Edge, and inside Outlook and Teams.The chat window.
Microsoft GraphMicrosoft's map of your work data: email, files, meetings, calendar, Teams, who reports to whom. Copilot (Premium) reads it to ground answers.The data an MCP connector exposes.
Work IQThe intelligence layer that lets Copilot and agents reason over work data, content and tools. Can be switched on or off.Your tool and context layer.
GroundingFeeding the model facts from a source (web, your files, Graph) before it answers, so the answer is about your stuff.Retrieval, RAG, context.
Copilot SearchOne search across all Microsoft 365 apps and connected outside sources, with a hand-off into chat.Semantic search over your workspace.
AgentA scoped version of Copilot with its own instructions, knowledge and actions. Prebuilt ones include Researcher and Analyst.A Claude Project or a skill.
ResearcherPrebuilt multistep research agent. Asks clarifying questions, then returns a cited report from web, work data, or both. Under Agents in Chat.Deep research mode.
AnalystPrebuilt data-analysis agent (runs code over your data). Listed "coming soon" for the home plan at launch.Code interpreter / analysis tool.
CoworkThe agent that acts on your behalf across Microsoft 365: sends email, schedules, builds files, posts in Teams, runs scheduled and event-driven tasks. Approves each sensitive step with you. Has built-in and custom skills.Claude Code, or Claude's Cowork.
Cowork skillA task-specific capability Cowork loads during a session (Word, Email, Scheduling, Deep Research, and up to 50 of your own).A SKILL.md file.
Agent builderNo-code agent creation inside Copilot Chat: instructions plus knowledge sources.Making a Claude Project.
Copilot StudioLow-code studio for agents, workflows and agent flows, with analytics and evaluations. Web app at copilotstudio.microsoft.com.A visual agent framework.
Declarative agentAn agent that uses Copilot's own model and orchestrator with your instructions, knowledge and API actions. No hosting.A system prompt plus tools, hosted for you.
Custom engine agentAn agent where you bring the model and orchestrator, hosted outside Microsoft 365 (Azure, Semantic Kernel, LangChain). Can act proactively.Your own Agent SDK app.
Agents ToolkitMicrosoft 365 Agents Toolkit: the VS Code extension for building declarative and custom engine agents in code.Agent SDK plus scaffolding.
PagesAn editable, shareable canvas that chat output can be sent to and worked on with others.An artifact.
NotebooksA space that holds a set of sources and lets you chat over them, with auto notes and mind maps. Light version in the Copilot app, full version in OneNote.NotebookLM.
FrontierMicrosoft's early-access preview program for work tenants. Gates things like Researcher's Computer Use, Model Council and Cowork's App skill.A beta program.
Copilot AcademyMicrosoft's guided course hub inside Viva Learning (Teams or web). Work account required.The official docs course.
Sources: What is Microsoft Copilot?, Cowork overview, Declarative vs custom engine agents, Copilot Studio overview, Get started with Researcher.
