Hands-on Session 1: Copilot on the Mac

Ten stations, about 85 minutes in total, split across three short days. Every station has a real prompt to paste, what to watch for as a power user, and a feedback box. Your answers save in this browser as you type. When you stop, press Copy all feedback and paste the block into the chat with Claude.

Files you will need: sample-sales.csv (108 rows of made-up sales) and briefing.md (the written briefing from the notebook). Download both to your Downloads folder before Day 1.

Day 1, about 30 minutes: the chat app

1. Plain chat, and the follow-up test

5 min. Copilot app, Chat tab.

Goal: learn whether Copilot knows what plan you are on, and whether a second message keeps the context of the first.

  1. Open the Copilot app. Make sure the Chat tab (top left) is selected, then click New chat.
  2. Paste prompt A and send it.
  3. Without starting a new chat, paste prompt B and send it.
  4. Look near the message box for a model or mode choice (words like Quick response, Think Deeper, or a model name). If there is one, switch it and send prompt A again in a new chat. Note any difference in depth or speed.
Prompt AI am a Microsoft 365 Premium subscriber using the Copilot app on a Mac. In five short lines, tell me what you can do for me inside this app that a plain web chatbot cannot. Be specific to my plan, and say plainly if you are not sure what plan I am on.
Prompt B (same chat)Turn that into a checklist of five things I can try this week, one line each, ordered from easiest to hardest.
What a power user watches for
  • Did it name your plan correctly, or guess? Guessing is a sign it does not see your account.
  • Did prompt B reuse the five lines from A, or start over? Reuse means the chat holds context.
  • Does the mode switch change anything you can see? Write down what, in one line.

2. Researcher: a real multi-step research job

15 min. Copilot app, Researcher (pinned in the left rail).

Goal: run one full Researcher cycle: question, clarifying questions, plan, report with sources.

  1. Click Researcher under Pinned in the left rail.
  2. Paste the prompt. Replace the bracket with one line about your actual job.
  3. It will ask two to four clarifying questions. Answer each in a few words. When it offers to begin, say Go ahead.
  4. Note the time you pressed Go ahead and the time the report arrived.
  5. Open two of the sources it cites and check that they say what the report claims.
PromptResearch this for me. I work as [one line about your job]. I want Microsoft 365 Copilot to save me at least two hours a week across email, meetings and documents. Find what Microsoft's own documentation and independent reviewers say actually saves time, what commonly disappoints people, and end with a ranked list of the five habits I should adopt first. Cite sources for every claim.
What a power user watches for
  • The clarifying questions are the product. Good answers here change the report more than a longer prompt does.
  • How long did it run? Researcher is slow by design. Minutes, not seconds.
  • Did the two sources you checked hold up? If one did not, that is worth a line in the feedback.
  • Look for a model or mode choice inside Researcher. If you see one, note the names.

3. Analyst: a question about a data file

10 min. Copilot app, Analyst (pinned in the left rail). Needs sample-sales.csv.

Goal: see Analyst write and run code against your file, and show its working.

  1. Click Analyst under Pinned.
  2. Attach sample-sales.csv from your Downloads folder (paperclip or plus icon by the message box).
  3. Paste prompt A and send it.
  4. When it answers, paste prompt B in the same chat.
Prompt AAnalyse the attached file. Which region grew revenue the most from the first three months to the last three months, and which product is dragging total revenue down? Show one chart that makes the answer obvious, and show me the code you ran.
Prompt B (same chat)Now assume the Gamma product is discontinued from July. Recalculate total revenue by region for July to September and tell me which region is hurt most, as a table.
What a power user watches for
  • The code it shows is Python. You do not need to read it, but check that it printed it rather than hiding it.
  • The honest answer for the data: East grows fastest, West shrinks most, and Gamma units drop by about a fifth across the nine months. If it says something else, the feedback box wants to know.
  • Did it ask before assuming what "first three months" meant, or just pick? Both are fine, but note which.
Day 2, about 30 minutes: notebooks, Word and Excel

4. Notebooks: chat that stays inside your sources

10 min. Copilot app, Notebooks. Needs briefing.md.

Goal: build a notebook from two sources and get answers that cite only those sources.

  1. Click Notebooks in the left rail, then New notebook. Name it Copilot learning.
  2. Add two sources: upload briefing.md, and add this web page as a link: https://nitrog1.github.io/m365-copilot-field-guide/
  3. Paste prompt A in the notebook's chat.
  4. Then paste prompt B.
  5. Look for a button that makes an audio overview or podcast from the notebook. If it exists, start one and note how long it takes.
Prompt AUsing only the sources in this notebook, list every agent available to me on Microsoft 365 Premium. One line each on what it is for. Flag any that are described as coming soon, preview, or being retired. If the sources disagree, say so.
Prompt BWrite me a five-question quiz on those agents. Multiple choice, four options each, answers at the end. Keep every option about the same length so the right one does not stand out.
What a power user watches for
  • Does every claim point back to a source? That is the whole point of a notebook over a plain chat.
  • Ask it something the sources do not cover, like "What does Copilot cost in Japan?" A good notebook says it cannot find that in the sources.
  • If the audio overview exists, this is the same idea as the NotebookLM podcast you already have. Compare them.

5. Word: draft, rewrite by talking, summarise

10 min. Microsoft Word.

Goal: produce a document you will reuse in stations 7 and 8, using Copilot three different ways.

  1. Open Word, create a blank document, and save it to OneDrive as How I will use Copilot this quarter. Confirm the AutoSave switch at the top is on.
  2. Click the Copilot button on the Home tab of the ribbon (or the Copilot icon that appears in the empty page). Choose the draft option and paste prompt A.
  3. When the draft is in, select one paragraph. Use the small Copilot icon that appears beside the selection and ask for a rewrite with prompt B.
  4. Open the Copilot pane on the right and paste prompt C.
  5. Look in the Copilot pane for an Agent Mode switch. If you find it, note where it is. Do not run it yet.
Prompt A (draft)Write a one-page briefing for my manager titled "How I will use Copilot this quarter". Three sections with short headings: email and meetings, research, and one small agent I will build. Confident, plain tone, no bullet points, under 350 words.
Prompt B (rewrite a selection)Make this half the length and remove every adjective that does not change the meaning.
Prompt C (Copilot pane)Summarise this document in three sentences, then list two questions my manager is likely to ask after reading it.
What a power user watches for
  • Three entry points: the draft box, the selection icon, the side pane. They behave differently. Which felt fastest?
  • Did the rewrite keep your meaning? Read it against the original.
  • The two questions from prompt C are a cheap way to pressure-test any document before sending it.

6. Excel: table, new column, pivot, chart

10 min. Microsoft Excel. Needs sample-sales.csv.

Gotcha: Copilot in Excel only works on a file that is saved in OneDrive with AutoSave on. A CSV on your desktop will show a greyed-out Copilot button.
  1. Open sample-sales.csv in Excel. Use File, Save As, choose OneDrive, change the format to Excel Workbook (.xlsx), and save. Confirm AutoSave is on.
  2. Click the Copilot button on the Home tab. Paste prompt A.
  3. Accept the changes it proposes. Then paste prompt B.
  4. Then paste prompt C.
  5. Look for an Agent Mode option in the Copilot pane. If present, try prompt C again through it and note the difference.
Prompt AFormat this data as a table and add a column called "revenue per unit" that divides revenue by units.
Prompt BAdd a PivotTable on a new sheet that shows total revenue by region (rows) and by month (columns), and highlight the region with the highest total.
Prompt CCreate a line chart of monthly revenue for each product, with a title and a legend, on a new sheet called Chart.
What a power user watches for
  • Does it preview the change before applying it, or apply straight away? Preview is what lets you say no.
  • Prompt B is the hardest. If it fails, try splitting it into two prompts and note which half failed.
  • Check the "revenue per unit" column against one row by hand. Alpha should be 120, Beta 85, Gamma 40.
Day 3, about 25 minutes: slides, Cowork, mail, and your verdict

7. PowerPoint: a deck from the Word document

5 min. Microsoft PowerPoint. Needs the document from station 5.

  1. Open PowerPoint, create a new blank presentation, and open the Copilot pane.
  2. Paste the prompt. When it asks which file, pick How I will use Copilot this quarter from OneDrive.
  3. When the deck appears, ask it to add speaker notes to every slide as a second message.
PromptCreate a five-slide presentation from my document "How I will use Copilot this quarter". One idea per slide, a short title on each, a clean simple design, and a closing slide with the three things I am asking my manager to agree to.
What a power user watches for
  • Did it find the document by name, or make you browse? Finding by name means it can see your OneDrive.
  • Is the content from your document, or generic filler? Check slide 2 against the Word text.

8. Cowork: hand it a task across apps

10 min. Copilot app, Cowork tab (next to Chat, top left). Cowork is in preview, so expect rough edges.

Goal: see an agent plan a task, ask permission, and act in your files.

  1. Click the Cowork tab at the top of the left rail.
  2. Paste the prompt. Read any plan it shows before you approve it.
  3. Approve each step it asks about. Write down what it asked permission for.
  4. Check OneDrive afterwards for the new file.
PromptFind my Word document "How I will use Copilot this quarter" in OneDrive. Write a three-sentence summary of it. Save that summary as a new Word document called "Copilot plan summary" in the same folder. Show me your plan and ask me before you create or change anything.
What a power user watches for
  • This is the Microsoft version of what Claude Code does: a plan, then actions with approvals. Compare the feel.
  • Did it ask before creating the file, as the prompt demanded? If it did not, that matters.
  • Look for a skills or settings area inside Cowork. Note the names of any built-in skills you see.

9. Outlook: summarise a thread, draft a reply

5 min. Microsoft Outlook with your personal mailbox. Skip if you have no personal account signed in.

  1. Open Outlook and pick a thread with at least four messages.
  2. Click the Copilot Summarize option at the top of the thread.
  3. Click Reply, open the Copilot menu in the reply, choose draft, and paste the prompt (swap the name).
  4. Look for a Coaching option on the Copilot menu and run it on your draft.
Prompt (draft reply)Reply to [name] saying I have read the thread, I agree with the last suggestion, and I will send what they need by Friday. Warm, brief, no exclamation marks.
What a power user watches for
  • Was the summary right about who said what? Mail summaries sometimes merge two people.
  • Coaching gives tone and clarity feedback. Is it useful, or generic?
